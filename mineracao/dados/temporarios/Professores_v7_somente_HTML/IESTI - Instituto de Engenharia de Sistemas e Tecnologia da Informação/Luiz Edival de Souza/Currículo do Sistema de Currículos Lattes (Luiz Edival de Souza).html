Automação do Sistema de Selagem e de Vedação do Eixo da Tampa de Turbina Hidráulicas
Descrição: O objetivo deste projeto é desenvolver um sistema capaz de controlar e monitorar o circuito de água responsável por realizar a selagem e a vedação do eixo da tampa da turbina. Projeto Software Livre CNPq - Manufatura Virtual
Descrição: Desenvolvimento de ferramentas de simulação de equipamentos utilizados em automação da manufatura utilizando recursos gráficos com realidade virtual. A demanda por equipamentos importados em instituições de ensino é um fato conhecido. Este problema se agrava quando a área envolvida é controle e automação da manufatura, onde o preço de um equipamento pode chegar a milhares de dólares. Entretanto, para que o treinamento de um profissional nesta área seja satisfatório, se faz necessário, além do estudo teórico, a observação e prática de diversos tipos de simulações em diversos tipos de equipamentos. A situação se complica quando técnicas de gerência da manufatura devem ser analisadas. Neste caso é necessária uma grande variedade de equipamentos para que se montar células de produção que compõe uma manufatura real. Somente desta forma os alunos poderiam testar metodologias e técnicas de gerência da produção e visualizar e analisar seu impacto. Para que este cenário seja implementado a instituição deve investir, além dos equipamentos, em um ambiente apropriado, manutenção, energia para operacionalizar, arcar com a rápida depreciação dos equipamentos dentre outros. Tudo isso demanda uma quantidade enorme de recursos. Para contornar esta situação este projeto propõe o desenvolvimento de um sistema capaz de montar, simular e controlar ambientes de manufatura. O sistema é dividido em três módulos independentes; ? Módulo Compositor (MC): capaz de importar elementos de softwares de modelagem 3D , construir motores e sensores. Esta definição irá gerar maquetes virtuais. ? Módulo de Programação (MP): uma vez definida a maquete virtual é necessária sua programação. O MP disponibiliza a linguagem padrão de programação pela IEC61131-3, ou seja, é igual à dos principais fabricantes de equipamentos. ? Módulo de Comunicação e Execução (ME): importa a maquete virtual gerada pelo MC e se comunica com o MP para a execução da lógica de controle. Utiliza técnicas de realidade vi.
