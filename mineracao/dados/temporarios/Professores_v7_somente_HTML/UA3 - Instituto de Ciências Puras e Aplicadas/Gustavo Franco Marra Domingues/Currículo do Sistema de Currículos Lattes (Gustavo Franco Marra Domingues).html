Projetos de pesquisa

2021 - Atual
Aplicações da Teoria Averaging a sistemas com bifurcações zero-Hopf
Descrição: Neste trabalho estudamos bifurcações do tipo zero-Hopf em sistemas autônomos em sistemas n-dimensionais com n maior ou igual a 3. Estamos interessados em usar o método de averaging para encontrar órbitas periódicas bifurcando nestes sistemas, bem como para detectar toros invariantes, o que demanda a análise dos ciclos limites que podem bifurcar do sistema médio associado..
Situação: Em andamento; Natureza: Pesquisa.

Integrantes: Gustavo Franco Marra Domingues - Coordenador / Murilo Rodolfo Cândido - Integrante.
2019 - 2020
Controle de Robôs via Curvas Implícitas
Descrição: O presente projeto propõe o estudo de uma técnica para controle de robôs móveis autônomos utilizando equações diferenciais no plano com ciclo limite atrator dado por uma curva implícita prescrita. Objetiva-se conhecer seus fundamentos teóricos bem como implementar algoritmos em ARDUINO e MAXIMA para realizar simulações e o controle de um robô real de duas rodas motrizes e uma roda passiva..
Situação: Concluído; Natureza: Pesquisa.
Alunos envolvidos: Graduação: (1) .

Integrantes: Gustavo Franco Marra Domingues - Coordenador / Ricardo Jorge Murakami - Integrante.
