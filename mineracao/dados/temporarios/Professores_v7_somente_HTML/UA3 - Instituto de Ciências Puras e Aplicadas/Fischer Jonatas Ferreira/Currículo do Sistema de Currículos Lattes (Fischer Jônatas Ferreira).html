LLM4IoT: Detecção e Correção de Falhas de Interação de Dispositivos com Grandes Modelos de Linguagem em Sistemas de Software IoT
Descrição: A Internet das Coisas (IoT) surgiu como uma mudança de paradigma, no qual os sistemas de software se estendem além dos computadores tradicionais para incluir uma variedade de dispositivos conectados. A gestão eficaz da qualidade interna e externa dos sistemas de software IoT é fundamental para garantir sua funcionalidade, otimizar recursos e lidar com suas complexidades únicas. O crescimento da IoT aumentou a necessidade de gerenciar desafios oriundos de sensores (ex., umidade, temperatura). O desenvolvimento de software para sistemas IoT enfrenta desafios. Por exemplo, as falhas de interação entre dispositivos representam riscos significativos, pois frequentemente se manifestam em contextos específicos, tornando sua detecção e resolução complexas. LLMs, como ChatGPT e Copilot, têm mostrado potencial para apoiar tarefas de desenvolvimento de software, como localização de falhas e refatoração. No entanto, seu potencial para lidar com desafios específicos da IoT ainda é pouco explorado. Este projeto investiga como os LLMs podem auxiliar os desenvolvedores a detectar e corrigir falhas de interação entre dispositivos em sistemas IoT. Ao abordar essa lacuna, o objetivo é melhorar a confiabilidade e a eficiência do desenvolvimento para IoT. Evidências preliminares sugerem que as capacidades dos LLMs em analisar grandes volumes de dados e gerar insights podem ser aplicadas de forma eficaz em contextos de IoT. Assim, propomos três estudos empíricos: (1) mineração de dados em repositórios públicos de software para analisar a evolução dos sistemas IoT, (2) realização de análises estáticas e dinâmicas para investigar falhas de interação entre dispositivos, e (3) utilização de questionários e entrevistas para obter insights de desenvolvedores e especialistas em IoT. Com base nesses estudos, nosso objetivo é desenvolver um método automatizado que utilize LLMs para detectar e corrigir falhas de interação entre dispositivos em sistemas IoT..

Descrição: O projeto tem como objetivo a criação de um livro sobre desenvolvimento de software para a Web, com a participação de alunos de graduação como autores dos conteúdos. A iniciativa surgiu a partir da aplicação da metodologia de Sala de Aula Invertida, na qual os alunos assumem um papel ativo no processo de aprendizagem.Por meio de seus trabalhos acadêmicos e projetos de conclusão de curso, os estudantes foram desafiados a desenvolver materiais didáticos e exemplos práticos sobre os temas abordados.
