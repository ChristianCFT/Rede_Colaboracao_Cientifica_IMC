2015 - Atual
Integrando avaliação de usabilidade no desenvolvimento de software baseado em modelo
Descrição: Soluções capazes de automatizar o processo de construção de aplicações Web vem sendo propostas de maneira crescente. Um ponto importante com relação às aplicações geradas de forma automatizada é o fato de que suas interfaces tendem a apresentar problemas recorrentes de usabilidade. Percebe-se, portanto, uma dualidade entre automação e usabilidade. Este projeto propõe a construção de um framework para avaliação de aplicações Web tomando como base uma ferramenta de avaliação de usabilidade denominada USABILICS. Com o desenvolvimento do framework proposto, espera-se reduzir a dualidade entre automação e usabilidade no desenvolvimento de aplicações Web..

Descrição: Desenvolvimento de uma infra-estrutura para captura, recuperação e apresentação de aulas em formato digital utilizando várias mídias: vídeo, áudio e slides estáticos ou animados. As aulas ou atividades práticas ministradas em uma sala ou anfiteatro devidamente instrumentado são capturadas por um software e armazenadas em um servidor, podendo ser recuperada pelo aluno a qualquer momento, de qualquer lugar onde haja acesso à Internet. 2000 - 2003
Projeto de Cooperação Internacional InCA-SERVE (hhtp://coweb.icmc.usp.br/incaserve)
Descrição: The aim of this research was to integrate flexible hypermedia infrastructures to automated capture environments in order to support long-term use. Previous work by the group at Georgia Tech has aimed at making capture a ubiquitous service at any point in time and over a short period of time. The real use of the infrastructure has created the interesting problem of having too much information available. The objective of the joint research was to find flexible and customizable information access solutions that scale over time, increasing the benefit of captured memories for the human as time passes and more information is captured. Our approach to this problem is to view capture as only one part of the information acquisition process in any given application. We introduce a spiral model for capture that stresses how the capture repository must be viewed as an ever-growing container for activities and knowledge that occurs before, during and after live capture sessions. As the repository grows over time, specialized automated services must be created that add structure by highlighting inter-relationships between the captured experiences and activities that occur outside of capture. Moreover, flexible services for structuring and accessing the information must be provided. Work that involved Abowd and Pimentel demonstrated how the digital media of the captured lecture can serve as an effective anchor for collaborative discussions and Web-based homework assignments..

Projetos de desenvolvimento

2007 - 2008
Sistema de Treinamento de Operadores para o Elo HVDC (Furnas)
Descrição: A operação do elo HVDC de Furnas constitui-se numa atividade complexa, que requer a preparação de operadores qualificados. Treinar pessoal técnico para a execução de ações operativas utilizando a própria mesa de operação do elo é temerário, já que uma ação incorreta poderia trazer prejuízos de milhões de reais. Este projeto de P&D tem como objetivo desenvolver um software produto capaz de simular os eventos reais com os quais os operadores do elo devem lidar. Executando em um sistema composto por 4 telas de cristal líquido, o software deverá ser capaz de simular com realismo o painel de controle do elo HVDC, possibilitando o treinamento eficaz e seguro de seus operadores..

Projetos de pesquisa
2015 - Atual
Integrando avaliação de usabilidade no desenvolvimento de software baseado em modelo
Descrição: Soluções capazes de automatizar o processo de construção de aplicações Web vem sendo propostas de maneira crescente. Um ponto importante com relação às aplicações geradas de forma automatizada é o fato de que suas interfaces tendem a apresentar problemas recorrentes de usabilidade. Percebe-se, portanto, uma dualidade entre automação e usabilidade. Este projeto propõe a construção de um framework para avaliação de aplicações Web tomando como base uma ferramenta de avaliação de usabilidade denominada USABILICS. Com o desenvolvimento do framework proposto, espera-se reduzir a dualidade entre automação e usabilidade no desenvolvimento de aplicações Web..
Situação: Em andamento; Natureza: Pesquisa.
Alunos envolvidos: Mestrado acadêmico: (2) .

Integrantes: Laércio Augusto Baldochi Júnior - Coordenador / Luiz Felipe Gonçalves - Integrante / Rafael Monroe Marcondes - Integrante.
