O desenvolvimento de um sistema distribuído baseado em nuvem para a captura e identificação de riscos naturais, como terremotos, deslizamentos de terra, inundações etc. 3. O desenvolvimento do algoritmo preditivo para evitar perdas durante desastres naturais. 4.
